# 醸造百選の陣取り

六角の日本地図で「醸造百選」の品を集めながら、県を自分の色に染めていく陣取りゲームです。スマートフォンの縦画面で遊べます。

## 遊び方

- 2〜4人で遊びます。1台を順に回す・コンピュータを相手にする・「部屋を作る／部屋に入る」で合言葉（数字四桁）を使い、別々の端末から遊ぶ、のどれかを選べます。
- サイコロを振り、出た目の数だけ、いる県から指で県をなぞって進みます。通った県・止まった県・目的地に、自分の色札がたまります。
- その県にたまった色札で、その県の品を取ります。県の色は、その県で取った品の重み（熟成の長さ）がいちばん大きい人の色になります。
- 決まった手数で、自分の色の県が多い人の勝ちです。

## 出典

- 品の名前と都道府県は、日本醸造学会「醸造百選」のリストによります。
- 時代と地域の出来事は、それぞれの出典へのリンクを画面に表示しています。
